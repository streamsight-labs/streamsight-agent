Follow the agent's own logs (they go to stderr, always):

  kubectl --namespace {{ .Release.Namespace }} logs -l app.kubernetes.io/instance={{ .Release.Name }} -f

{{- if eq .Values.export.mode "file" }}

Batches are written to an emptyDir, one JSON object per line. The volume lives
and dies with the pod, so this mode is for smoke-testing the collector, not for
durable storage:

  kubectl --namespace {{ .Release.Namespace }} exec -it deploy/{{ include "streamsight-agent.fullname" . }} -- tail -f {{ .Values.export.file.path }}

Switch to a real destination with:

  --set export.mode=http --set export.http.endpoint=https://... --set export.http.apiKey=...
{{- end }}

{{- if eq .Values.export.mode "stdout" }}

Batches are written to stdout as JSONL and the agent's logs go to stderr, so
the pod log stream is machine-parseable. Pipe it through a log shipper, or:

  kubectl --namespace {{ .Release.Namespace }} logs deploy/{{ include "streamsight-agent.fullname" . }} | jq .
{{- end }}
