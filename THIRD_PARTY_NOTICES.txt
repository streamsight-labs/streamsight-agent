THIRD-PARTY SOFTWARE NOTICES
============================

streamsight-agent is licensed under the Apache License, Version 2.0; see
LICENSE. This file covers the third-party code that is compiled into it.

The agent is built with CGO_ENABLED=0 and is statically linked, so every module
below is part of the executable itself. The binaries attached to a GitHub
release and the image published to ghcr.io are therefore binary redistributions
of all six, and every one of them is BSD-3-Clause. That license's second clause
requires a binary redistribution to reproduce the copyright notice, the list of
conditions and the disclaimer "in the documentation and/or other materials
provided with the distribution". This file is that material, which is why it is
attached to each release alongside the binaries (.github/workflows/release.yml)
and copied into the image under /usr/local/share/streamsight-agent (Dockerfile)
rather than only sitting in the source tree, where it would reach nobody who
consumes the agent as an artifact.

This project ships no NOTICE file and needs none. Apache-2.0 section 4(d) binds
a redistributor only "If the Work includes a NOTICE text file", and none of the
six modules includes one -- checked against the module cache, not assumed. A
NOTICE here would be a convention; the BSD attribution below is the obligation.

The list is the linked set reported by `go list -deps ./...`, which is narrower
than the module graph: `go list -m all` also shows golang.org/x/net, x/sys,
x/term and x/text, but those are test-only dependencies of x/crypto and
`go mod why` reports that the main module does not need them. No package of
theirs is compiled in, so they are not redistributed and are not listed here.

No third-party source is vendored or copied into this repository.
